================================================================================
            Interception 驱动安装与使用说明
================================================================================

版本: v2.1
更新日期: 2026-07-15
适用系统: Windows 10 / 11 64-bit

================================================================================
1. 概述
================================================================================

Interception 是一个内核级键盘/鼠标拦截驱动，本工具用它实现 WeGame 登录界面中
账号密码的可靠输入（WeGame 支持多账号单独登录）。

需要安装两个组件：
  - interception.sys  — 内核驱动文件（安装到系统目录，伪装为 keyboard.sys）
  - interception.dll  — 用户态通信 DLL（项目目录已包含）

注意：本工具的安装程序将 interception.sys 伪装为 keyboard.sys 安装到系统，
驱动服务名也是 keyboard（而非 interception），这是为了兼容系统签名策略。
后续所有操作请使用 keyboard 作为服务名。

验证驱动状态：
    sc query keyboard           # 应显示 STATE = RUNNING

3. 安装方法
================================================================================

本工具安装程序已包含一键安装脚本（install_interception.bat），
以管理员身份运行即可。

---------- 步骤一：以管理员身份运行 install_interception.bat ----------

在安装目录中，右键点击 install_interception.bat → 以管理员身份运行。

脚本会自动：
1. 将 interception.sys 复制到 C:\Windows\System32\drivers\keyboard.sys
2. 创建驱动服务（服务名：keyboard）
3. 启动驱动服务

---------- 步骤二：重启电脑 ----------

  ⚠️ 重要：安装后必须重启电脑，驱动才能加载。

================================================================================
4. 验证安装
================================================================================

重启后，打开管理员 CMD，执行：

    sc query keyboard

输出应包含：
    STATE               : 4  RUNNING

或者运行程序 → 开发者测试 → 检测键盘状态，显示「Interception 可用」。

注意：服务名为 keyboard（非 interception），因为驱动文件伪装为系统键盘驱动。

================================================================================

驱动文件签名信息：

  - 颁发者: GlobalSign CodeSigning CA - G2
  - 证书有效期: 2011-10-21 ~ 2012-10-21（已过期，有时间戳）
  - 签名类型: Authenticode
  - 签名状态: Valid（有过期时间戳的 Authenticode 签名）

驱动签名虽然过期，但带有 RFC 3161 时间戳，Windows 仍视为有效签名。
在大多数系统上可正常加载，无需开启测试模式。

6. 常见问题与解决方案
================================================================================

---------- 问题 1：sc start 报错 577 "无法验证数字签名" ----------

原因：系统开启了 Secure Boot 或 HVCI（内存完整性），阻止加载非 WHQL 驱动。

解决方案（按优先级）：

  A. 关闭内存完整性（推荐，不影响游戏）
     1. 打开 Windows 安全中心 → 设备安全性 → 内核隔离详细信息
     2. 关闭「内存完整性」
     3. 重启电脑

  B. 关闭 Secure Boot（进 BIOS 设置）
     进入主板 BIOS → Security → Secure Boot → Disabled

  C. 开启测试模式（最后手段，可能影响游戏）
     以管理员身份运行：
         bcdedit /set testsigning on
     重启后生效。注意：测试模式下 EasyAntiCheat 等反作弊系统可能阻止游戏启动。

---------- 问题 2：sc start 报错 183 "文件已存在" ----------

原因：驱动服务已创建但设备对象冲突，或驱动已在运行。

解决方案：
  1. 检查状态：sc query interception
  2. 如果显示 STOPPED → 重启电脑后重试
  3. 如果仍失败 → 先删除再重建：
       sc stop interception
       sc delete interception
       sc create interception type= kernel binPath= "C:\Windows\System32\drivers\interception.sys"
       重启电脑

---------- 问题 3：sc start 报错 193 "不是有效的应用程序" ----------

原因：interception.sys 文件不完整或损坏（提取方式不正确）。

解决方案：
  1. 重新提取驱动文件（使用上面的 Python 脚本）
  2. 确认文件大小约 18536 字节（x64 版本）
  3. 检查签名：Get-AuthenticodeSignature interception.sys
     应显示 Status=Valid，Signer=Francisco Lopes da Silva

---------- 问题 4：驱动安装成功但程序检测不到 ----------

原因：interception.dll 不在正确位置。

解决方案：
  1. 确认项目目录下有 interception.dll（约 11KB）
  2. DLL 搜索顺序：项目目录 → Interception-master/library/ → System32
  3. 如果是打包后的 exe，DLL 会在 exe 同级目录

---------- 问题 5：安装驱动后游戏无法启动 ----------

原因：部分反作弊系统（EasyAntiCheat、BattlEye）检测到 Interception 驱动会阻止游戏启动。

解决方案：
  1. 运行自动化工具前安装驱动
  2. 玩游戏前卸载驱动：
       sc stop interception
       sc delete interception
  3. 或使用双启动项方案（一个开启测试模式用于自动化，一个正常模式用于游戏）

7. 工具集成说明
================================================================================

项目相关文件：
  - interception_keyboard.py   — Python 封装模块（ctypes 调用 interception.dll）
  - interception.dll           — Interception 通信 DLL（项目根目录，约 11KB）
  - 三角洲自动工具.spec         — PyInstaller 配置（已配置嵌入 interception.dll）

interception_keyboard.py 功能：
  - is_available()：检查 Interception 驱动和 DLL 是否可用
  - send_string(text, interval)：逐字符发送按键（扫描码方式）
  - send_key(char, interval)：发送单个按键事件
  - get_backend()：返回后端名称 "Interception"
  - DLL 搜索路径：项目目录 → Interception-master/library/ → System32 → sys._MEIPASS

自动化登录流程（automation_runner.py _login_account）：
  1. 杀进程（WeGame/三角洲）
  2. 打开 WeGame → 等待窗口
  3. 图像识别双击 account_select（左偏 15px）→ Ctrl+A + Backspace 清空旧账号
  4. Interception 驱动级键盘输入账号
  5. 图像识别点击 Input（密码框）→ Interception 输入密码
  6. 图像识别点击 Sign-in 登录

8. 驱动卸载方法
================================================================================

停止驱动：
    sc stop interception

删除服务：
    sc delete interception

删除驱动文件：
    del C:\Windows\System32\drivers\interception.sys

卸载后重启电脑生效。

9. 快速安装脚本（一键安装）
================================================================================

安装目录下的 install_interception.bat 内容如下：

    @echo off
    echo === Interception 驱动安装 ===

    REM 检查是否已安装
    sc query keyboard >nul 2>&1
    if %errorlevel% equ 0 (
        echo 驱动服务已存在（keyboard），跳过安装。
        goto :check
    )

    REM 复制驱动文件（伪装为 keyboard.sys）
    echo 复制驱动文件...
    copy /Y "%~dp0interception.sys" "C:\Windows\System32\drivers\keyboard.sys"
    if %errorlevel% neq 0 (
        echo 复制失败！请以管理员身份运行此脚本。
        pause
        exit /b 1
    )

    REM 创建服务（服务名：keyboard）
    echo 创建驱动服务...
    sc create keyboard type= kernel binPath= "C:\Windows\System32\drivers\keyboard.sys"
    if %errorlevel% neq 0 (
        echo 创建服务失败！
        pause
        exit /b 1
    )

    echo.
    echo 安装完成！请重启电脑使驱动生效。
    echo.

    :check
    echo 验证安装：
    sc query keyboard
    echo.
    pause

使用方法：
  1. 将 interception.sys 和此 bat 文件放在同一目录
  2. 右键 bat 文件 → 以管理员身份运行
  3. 重启电脑
