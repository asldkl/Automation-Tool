用途: 辅助开发者快速了解项目结构和各模块功能

【项目概述】
基于图像识别（OpenCV 模板匹配）+ OCR 文字识别（RapidOCR）的《三角洲行动》游戏日常自动化工具。
支持 WeGame 直接登录、多账号轮换、冷却执行、一键出售、冷却管理、邮件通知。
内置模板基于 2560×1440（2K）屏幕 + 游戏 1440×900 制作。

【运行流程】

1. 启动 → 单实例检查 → 预初始化 OCR 引擎 → 服务器验证（机器指纹+有效期） → 加载设置 → 显示主界面
2. 用户点击"开始运行"或冷却到期自动触发
3. 每天首次运行时再次验证服务器（确保即使程序长时间不退出，每天也会重新校验）
4. 启动心跳线程（每30秒同步账号状态）
5. 清理进程（QQ/WeGame/三角洲）
6. 逐个账号：
   a. 暂停检查（跳过已暂停的账号，状态标记为 "已暂停"）
   b. 冷却检查（跳过冷却中的账号，状态标记为 "cooling"）
   c. 启动 WeGame → 双击账号选择框 → Interception 输入账号 → 点击密码框 → 输入密码 → 点击登录
   d. 找到三角洲图标 → 资产识别 → 启动游戏
   e. 可选：资产识别（等待 4 秒后截图指定区域，RapidOCR 识别，过滤"现有资产"等文字）
   f. 进入烽火地带 → 特勤处
   g. 可选：领取邮箱货币
   h. 执行选中的设施操作（制造/收取/产出）
   i. 可选：一键出售
   j. 关闭游戏/WeGame
   l. 记录冷却时间
7. 所有账号完成 → 停止心跳线程 → 发送邮件报告 → 恢复睡眠设置
8. 如果设置了延迟关机（且非手动终止） → 等待指定分钟后关机

【OCR 识别机制】

1. 智能匹配（find_and_click_smart）：
   - 优先尝试 OCR 文字识别（如果已配置且引擎可用）
   - OCR 超时自动回退到图像匹配（受 ocr_downgrade_enabled 控制）
   - 单 var_name 连续失败 3 次临时禁用 OCR（5分钟自动恢复），不影响其他模板
   - _IMAGE_TO_VAR 从 TEMPLATE_CAPTURE_LIST 自动生成（v1.3.0）

2. OCR 配置（per-template）：
   - 每个模板可配置独立的 OCR 识别区域和目标文本
   - 通过模板上传向导的「OCR识别」按钮配置
   - 配置存储在 settings.json 的 ocr_configs 字段

3. 全局 OCR 设置：
   - 统一配置 OCR 区域、置信度、目标文本列表
   - 可一键应用到所有模板
   - 禁用时自动清理相关 ocr_configs

4. 资产识别（automation_runner._recognize_asset）：
   - 游戏启动后自动识别屏幕指定区域的资产数值
   - 使用独立的 RapidOCR 引擎缓存（_ocr_engine），首次创建后复用
   - 直接传入 numpy 数组（不做 BGR 转换），与 utils.ocr_recognize 不同
   - 正则匹配格式：(\d+\.?\d*)\s*([KMBkmb])，如 "1.2M", "500K"
   - 设置界面支持区域框选（全屏 overlay）和测试识别

【技术栈】

Python 3.8+ / Tkinter / OpenCV / RapidOCR (onnxruntime) / PyAutoGUI / psutil / pywin32 / pystray+Pillow / PyInstaller

服务器端: Python / FastAPI / uvicorn

【Interception 驱动状态】

驱动文件：C:\Windows\System32\drivers\interception.sys
服务名称：interception（内核驱动，手动启动）
DLL 依赖：interception.dll（项目目录，打包时嵌入 exe）
签名状态：Authenticode 有效（GlobalSign CodeSigning CA 签发）
工作模式：正常模式（Windows 测试签名关闭）
加载条件：本机 Code Integrity 在每次启动时禁用 WHQL 驱动强制（Event 3085），
          使非 WHQL 交叉签名驱动可正常加载

注意事项：
- 在新电脑部署时，需安装 Interception 驱动并确保签名可被系统接受
- 如果目标系统启用了 WHQL 强制（Secure Boot / HVCI），驱动需在测试模式下使用
- 本机不开启测试模式即可工作的原因：Code Integrity 启动时自动禁用了 WHQL 强制
