1. 项目概述
================================================================================

本工具是《三角洲行动》游戏的日常自动化工具，基于图像识别技术，支持：
- QQ 登录 + WeGame 快捷登录
- 多账号管理
- 定时执行
- 电源管理
- 邮件通知
- 机器指纹绑定（防复制/防滥用）
- 远程有效期控制（服务器端校验）
- 账号状态实时同步（心跳推送）

3. 防破解保护机制
================================================================================

v1.0.3 采用全新的服务器端验证架构，彻底移除了本地有效期校验：

旧机制（已移除）：
    - 本地 XOR 加密有效期（crypto_utils.py）
    - 多时间源交叉验证（淘宝/苏宁/世界时间API）
    - 本地时间戳防篡改（~/.delta_auto_timestamp.dat）
    - 以上代码已全部删除，不再使用

新机制（v1.0.3）：
    - 机器指纹绑定：通过硬件序列号生成唯一指纹，程序只能在授权电脑运行
    - 服务器端有效期校验：有效期由服务器统一管理，无法本地篡改
    - 双重验证：启动时验证 + 每天首次运行任务时验证
    - 心跳同步：运行时每30秒推送账号状态到服务器

4. 机器指纹机制详解
================================================================================

文件: machine_fingerprint.py

----------------------------------------
4.1 指纹生成算法
----------------------------------------

1. 通过 WMI 获取硬盘序列号：
   命令: wmic diskdrive get serialnumber

2. 通过 WMI 获取主板序列号：
   命令: wmic baseboard get serialnumber

3. 拼接两个序列号（格式: "DISK_SERIAL:BOARD_SERIAL"）

4. 对拼接字符串进行 SHA256 哈希

5. 取哈希值前32个十六进制字符作为机器指纹

降级方案：如果 WMI 调用失败，使用 hostname + MAC 地址作为备用标识

----------------------------------------
4.2 核心函数
----------------------------------------

    get_machine_id() -> str
        返回32位十六进制机器指纹字符串
        示例: "a1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d6"

----------------------------------------
4.3 指纹验证流程
----------------------------------------

客户端启动时：
    1. 调用 get_machine_id() 获取本机指纹
    2. 发送 POST 到 /api/v1/validate，携带 machine_id
    3. 服务器检查白名单 + 有效期
    4. 返回 granted 或 denied

如果验证失败，弹窗显示本机指纹，方便用户复制给管理员

================================================================================
5. 服务器验证流程
================================================================================

----------------------------------------
5.1 启动时验证（gui_app.py → App.__init__）
----------------------------------------

    1. 获取机器指纹
    2. POST /api/v1/validate {"machine_id": "xxx", "current_date": "2026-05-28"}
    3. 如果返回 "granted" → 正常启动
    4. 如果返回 "denied" → 弹窗显示指纹 + 错误原因，退出程序
    5. 如果服务器不可达 → 弹窗显示指纹 + "服务器不可用"，退出程序

----------------------------------------
5.2 每天首次运行验证（gui_app.py → run_script_main）
----------------------------------------

    1. 检查 _last_validated_date 是否等于今天
    2. 如果不是今天 → 重新调用 /api/v1/validate
    3. 验证通过 → 更新 _last_validated_date
    4. 验证失败 → 弹窗显示指纹，root.destroy() 退出程序

这确保了即使程序长时间不退出，每天也会重新验证一次

----------------------------------------
5.3 验证失败弹窗
----------------------------------------

所有验证失败的弹窗都包含本机机器指纹，格式：
    "机器指纹: a1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d6"
    "请联系管理员将此指纹添加到白名单"

6. 心跳同步机制
================================================================================

文件: gui_app.py（_start_heartbeat / _heartbeat_loop / _send_heartbeat）

----------------------------------------
6.1 心跳线程
----------------------------------------

- 在任务开始时启动，任务结束时停止
- 每30秒发送一次心跳到服务器
- 使用 daemon 线程，不阻塞主程序退出

----------------------------------------
6.2 心跳数据格式
----------------------------------------

POST /api/v1/heartbeat
{
    "machine_id": "a1b2c3d4...",
    "accounts": [
        {"name": "qq1.png", "status": "running"},
        {"name": "qq2.png", "status": "cooling"},
        {"name": "qq3.png", "status": "success"}
    ],
    "is_running": true
}

----------------------------------------
6.3 账号状态值
----------------------------------------

- "running"  - 正在执行自动化任务
- "cooling"  - 跳过（冷却中）
- "success"  - 本账号执行成功
- "failed"   - 本账号执行失败
- "idle"     - 空闲/未执行

----------------------------------------
6.4 状态更新时机
----------------------------------------

在 run_script_main() 中：
    - 开始处理账号 → "running"
    - 冷却跳过 → "cooling"
    - 执行成功 → "success"
    - 执行失败 → "failed"
    - 任务全部完成 → 停止心跳线程

7. 如何管理用户（白名单/有效期）
================================================================================

----------------------------------------
7.1 服务器管理接口
----------------------------------------

所有管理接口需要 ADMIN_SECRET_KEY 认证（Header: Authorization）

1. 添加机器到白名单：
   POST /api/v1/admin/add_to_whitelist
   Body: {"machine_id": "a1b2c3d4..."}

2. 移除机器：
   POST /api/v1/admin/remove_from_whitelist
   Body: {"machine_id": "a1b2c3d4..."}

3. 设置独立有效期：
   POST /api/v1/admin/set_user_expiry
   Body: {"machine_id": "a1b2c3d4...", "expiry": "2026-12-31"}

4. 查看所有用户：
   GET /api/v1/admin/get_all_users

5. 查看机器实时状态：
   GET /api/v1/admin/get_machine_status

----------------------------------------
7.2 有效期管理逻辑
----------------------------------------

- 全局默认有效期：user_data.json 中的 "expiry_date" 字段
- 用户独立有效期：user_data.json → users → {machine_id} → expiry
- 优先级：用户独立有效期 > 全局默认有效期
- 修改有效期只需调用 set_user_expiry 接口，无需重新打包客户端

----------------------------------------
7.3 密钥配置
----------------------------------------

服务器端（server.py）：
    CLIENT_KEY = "Client_Normal_Key_2026"        # 客户端验证用
    ADMIN_SECRET_KEY = "Super_Admin_Secret_8888"  # 管理员接口用

客户端（config.py → DEFAULT_SETTINGS）：
    server_url = "http://112.74.106.69:8000"
    client_key = "Client_Normal_Key_2026"

8. 打包说明
================================================================================

----------------------------------------
8.1 安装依赖
----------------------------------------

    pip install opencv-python numpy pyautogui psutil pywin32 pystray pillow pyinstaller

----------------------------------------
8.2 打包命令
----------------------------------------

    pyinstaller 三角洲自动工具.spec

----------------------------------------
8.3 打包配置（三角洲自动工具.spec）
----------------------------------------

关键配置:
    - hiddenimports: 包含 machine_fingerprint 模块
    - datas: 包含 picture 目录中的图片资源
    - icon: 程序图标

----------------------------------------
8.4 添加新模块到打包
----------------------------------------

如果添加了新的 Python 模块，需要在 .spec 文件的 hiddenimports 列表中添加：

    hiddenimports=['machine_fingerprint', '新模块名'],

----------------------------------------
8.5 服务器部署
----------------------------------------

1. 将 server.py 上传到云服务器
2. 安装依赖: pip install fastapi uvicorn
3. 启动: python server.py 或 uvicorn server:app --host 0.0.0.0 --port 8000
4. 管理后台: 将图形化可视管理后台代码部署为 HTML 页面

9. 常见问题
================================================================================

Q: 如何测试机器指纹验证？
A:
    1. 运行 python machine_fingerprint.py 查看本机指纹
    2. 确保该指纹在服务器白名单中
    3. 如果不在白名单，调用 /api/v1/admin/add_to_whitelist 添加

Q: 服务器不可达时程序会怎样？
A:
    程序会弹窗显示本机指纹和"服务器不可用"提示，然后退出。
    不会降级到本地验证，确保安全性。

Q: 用户说程序打不开怎么办？
A:
    1. 让用户截图弹窗中的机器指纹
    2. 在管理后台调用 add_to_whitelist 添加该指纹
    3. 如果是有效期问题，调用 set_user_expiry 延长有效期

Q: 如何查看哪些机器在线？
A:
    调用 GET /api/v1/admin/get_machine_status，返回所有机器的实时状态。
    超过5分钟无心跳的机器会被标记为离线。

Q: 心跳数据不更新了怎么办？
A:
    1. 检查客户端程序是否还在运行
    2. 检查服务器是否在线
    3. 心跳停止不影响本地自动化功能，只是无法远程监控

Q: 如何修改服务器地址？
A:
    修改 config.py 中 DEFAULT_SETTINGS 的 server_url 字段，重新打包。
    或者让用户在 ~/.delta_auto_settings.json 中手动修改。

Q: 打包后程序无法启动？
A:
    1. 检查 machine_fingerprint 是否在 hiddenimports 中
    2. 检查图片资源是否正确打包
    3. 查看 dist 目录下的错误日志
    4. 确保目标机器能访问服务器
