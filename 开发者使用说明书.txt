1. 项目概述
================================================================================

本工具是《三角洲行动》游戏的日常自动化工具，基于图像识别技术，支持：
- QQ 登录 + WeGame 快捷登录
- 多账号管理
- 定时执行
- 电源管理
- 邮件通知
- 联网时间校验（防破解保护）

3. 防破解保护机制
================================================================================

本工具采用4层保护机制：

第1层：多重时间源交叉验证
    - 同时从淘宝、苏宁、世界时间API获取时间
    - 取中位数作为可靠时间，排除异常值
    - 防止单一时间源被篡改

第2层：时间偏移检测
    - 记录每次成功运行时的网络时间
    - 下次启动时检测系统时间是否被回拨
    - 如果当前时间 < 上次记录时间，拒绝启动

第3层：有效期加密存储
    - 有效期不再明文存储在代码中
    - 使用 XOR 加密，密钥分散存储在多个变量中
    - 运行时动态解密

第4层：关键代码段混淆
    - 添加干扰函数，增加逆向分析难度
    - 错误消息使用 GBK 编码存储
    - 干扰函数使用看似真实的注释

4. 如何更改有效期（重要）
================================================================================

有效期的更改需要修改两个文件：crypto_utils.py 和设计文档。

----------------------------------------
步骤 1: 计算新的加密字节
----------------------------------------

首先，你需要计算新日期的加密字节。使用以下 Python 代码：

    # 假设新有效期是 2027年12月31日
    year = 2027
    month = 12
    day = 31

    # 密钥（固定值，不要修改）
    key = bytes([0x42, 0x37, 0x19, 0x88])

    # 将日期转换为字节
    plain = bytes([year >> 8, year & 0xFF, month, day])

    # XOR 加密
    encrypted = bytes(a ^ b for a, b in zip(plain, key))

    print(f"新的加密字节: {encrypted}")
    print(f"字节列表: {list(encrypted)}")

----------------------------------------
步骤 2: 修改 crypto_utils.py
----------------------------------------

打开 crypto_utils.py 文件，找到以下代码（约第22行）：

    _ENCRYPTED_EXPIRY = bytes([0x45, 0xDD, 0x1E, 0x89])

将其替换为新的加密字节，例如：

    _ENCRYPTED_EXPIRY = bytes([0xXX, 0xXX, 0xXX, 0xXX])

其中 0xXX 是步骤1计算出的新字节值。

----------------------------------------
步骤 3: 验证修改
----------------------------------------

运行以下命令验证：

    python crypto_utils.py

输出应该显示新的有效期日期。

----------------------------------------
步骤 4: 更新设计文档（可选）
----------------------------------------

打开 docs/superpowers/specs/2026-05-19-anti-crack-protection-design.md
找到以下代码：

    _ENCRYPTED_EXPIRY = bytes([0x45, 0xDD, 0x1E, 0x89])  # 2026年7月1日加密后

更新为新的值和日期注释。

----------------------------------------
步骤 5: 重新打包
----------------------------------------

运行打包命令：

    pyinstaller 三角洲自动工具.spec

新的 exe 文件将包含更新后的有效期。

----------------------------------------
完整示例：将有效期改为 2027年12月31日
----------------------------------------

    # 1. 计算加密字节
    key = bytes([0x42, 0x37, 0x19, 0x88])
    plain = bytes([2027 >> 8, 2027 & 0xFF, 12, 31])
    encrypted = bytes(a ^ b for a, b in zip(plain, key))
    # 结果: encrypted = bytes([0x45, 0xDD, 0x1E, 0x89]) 实际计算结果

    # 2. 修改 crypto_utils.py 第22行
    _ENCRYPTED_EXPIRY = bytes([计算出的字节])

    # 3. 验证
    python crypto_utils.py

    # 4. 重新打包
    pyinstaller 三角洲自动工具.spec

5. 加密机制详解
================================================================================

----------------------------------------
5.1 有效期加密
----------------------------------------

文件: crypto_utils.py
位置: 第12-47行

加密算法: XOR（异或）
密钥: 4字节，分散存储在 _K1, _K2, _K3, _K4 变量中
密钥值: 0x42, 0x37, 0x19, 0x88

加密过程:
    1. 将日期转换为4字节: [年份高8位, 年份低8位, 月, 日]
    2. 与密钥进行 XOR 运算
    3. 结果存储在 _ENCRYPTED_EXPIRY 变量中

解密过程:
    1. 读取 _ENCRYPTED_EXPIRY 字节
    2. 与密钥进行 XOR 运算（XOR 是对称的）
    3. 将结果转换为日期

----------------------------------------
5.2 时间戳加密
----------------------------------------

文件: crypto_utils.py
位置: 第50-116行

存储位置: ~/.delta_auto_timestamp.dat
文件格式: 8字节时间戳 + 4字节校验和（共12字节）

加密过程:
    1. 将时间戳转换为8字节大端序整数
    2. 与密钥进行 XOR 运算（循环使用密钥）
    3. 计算 MD5 校验和（取前4字节）
    4. 写入文件

解密过程:
    1. 读取文件（验证长度为12字节）
    2. 验证校验和
    3. 与密钥进行 XOR 运算解密
    4. 转换为 datetime 对象

6. 时间源配置
================================================================================

文件: config.py
位置: 第26-42行

当前配置了3个时间源：

    TIME_SOURCES = [
        {
            "name": "淘宝",
            "url": "http://api.m.taobao.com/rest/api3.do?api=mtop.common.getTimestamp",
            "timeout": 3
        },
        {
            "name": "苏宁",
            "url": "http://quan.suning.com/getSysTime.do",
            "timeout": 3
        },
        {
            "name": "世界时间",
            "url": "http://worldtimeapi.org/api/timezone/Asia/Shanghai",
            "timeout": 5
        }
    ]

添加新时间源:
    1. 在 TIME_SOURCES 列表中添加新的字典
    2. 在 gui_app.py 中添加对应的 _fetch_time_xxx() 函数
    3. 在 get_verified_network_time() 的 fetchers 列表中添加新函数

7. 代码混淆说明
================================================================================

文件: gui_app.py
位置: 第32-55行

----------------------------------------
7.1 干扰函数
----------------------------------------

_v1_check(): 校验许可证完整性
_v2_check(): 验证环境配置
_v3_check(): 检查系统兼容性

这些函数从未被调用，仅用于干扰逆向分析。
如果需要更有效的混淆，可以将它们集成到实际代码流程中。

----------------------------------------
7.2 混淆的错误消息
----------------------------------------

_ERR_EXPIRY: 软件已过期（GBK编码）
_ERR_TIME: 时间异常（GBK编码）
_decode_err(): 解码函数

错误消息使用 GBK 字节编码存储，运行时动态解码。
增加逆向分析时识别关键字符串的难度。

9. 常见问题
================================================================================

Q: 如何测试防破解保护是否生效？
A:
    1. 修改系统时间到有效期之后，启动程序应显示"软件已过期"
    2. 修改系统时间到上次运行时间之前，应显示"时间异常"
    3. 断网启动，如果有本地记录应允许运行，否则应显示错误

Q: 加密密钥泄露了怎么办？
A:
    修改 crypto_utils.py 中的 _K1, _K2, _K3, _K4 值，然后重新计算有效期加密字节。

Q: 时间源API失效了怎么办？
A:
    1. 在 config.py 的 TIME_SOURCES 中更新或替换失效的URL
    2. 在 gui_app.py 中更新对应的 _fetch_time_xxx() 函数

Q: 如何禁用防破解保护（用于开发测试）？
A:
    在 gui_app.py 的 main() 函数中，注释掉时间校验相关的代码。
    注意：仅用于开发测试，不要发布禁用保护的版本。

Q: 打包后程序无法启动？
A:
    1. 检查 crypto_utils 是否在 hiddenimports 中
    2. 检查图片资源是否正确打包
    3. 查看 dist 目录下的错误日志
