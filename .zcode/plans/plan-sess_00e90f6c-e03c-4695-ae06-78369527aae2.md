把 LCA 式「视觉 Agent」精简集成到三角洲工具，专门处理 WeGame 登录后可能弹出的**点击式图片验证码**；默认关闭，配置 AI 供应商后才启用；支持国内主流视觉模型（OpenAI 兼容接口统一接入）。

## 1. 新模块 ai_visual_captcha.py（根目录）

- **供应商预设下拉**（切换自动填地址+模型，支持自定义）：
  - 智谱 https://open.bigmodel.cn/api/paas/v4 + glm-4v-flash（免费）
  - 阿里百炼 https://dashscope.aliyuncs.com/compatible-mode/v1 + qwen-vl-plus
  - 月之暗面 https://api.moonshot.cn/v1 + moonshot-v1-8k-vision-preview
  - 豆包（火山方舟）https://ark.cn-beijing.volces.com/api/v3 + doubao-1.5-vision-lite
  - 硅基流动 https://api.siliconflow.cn/v1 + Qwen/Qwen2.5-VL-7B-Instruct
  - 自定义（只存 base_url/model）
- **solve_captcha(app, stop_event)**：最多 N 轮（默认 5）循环：
  1. 线程安全隐藏日志遮罩（gui_app.hide_log_overlay，防遮罩入镜）→ pyautogui 彩色全屏截图 → JPEG base64
  2. POST {base_url}/chat/completions（temperature=0，图走 image_url base64 data URL，国内五家接口格式一致）
  3. 解析 AI 返回 JSON（容忍 ```json 包裹）：{"captcha": bool, "type": "click"|"slider"|"none", "targets": [{text, bbox/point, scale}]}
  4. 坐标归一化（scale 1000/1024/0-1 → 像素；bbox 取中心，优先 bbox）
  5. captcha=false → 结束返回；type=slider → 日志提示手动处理并返回；click → 按顺序 smooth_move_to + 拟人点击（随机间隔），等 2.5 秒后重新截图复核，验证码消失即成功
- test_captcha(app)：设置窗口「测试」按钮调用，独立线程运行，结果只输出日志

## 2. 登录流程挂载（automation_runner._login_account）

登录结果轮询中「既未见重登按钮也未见三角洲图标」的第三态分支：
- 若 enable_ai_visual_captcha 且 base_url/model/api_key 齐全 → 调 solve_captcha（内部自带轮次与复核）
- 处理后立即再探测一次三角洲图标，见图标即登录成功；否则继续原有轮询
- 未启用/未配置时行为与现在完全一致
