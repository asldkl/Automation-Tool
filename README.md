# 三角洲行动自动化工具

基于图像识别的《三角洲行动》游戏日常自动化工具，支持 QQ 登录 + WeGame 快捷登录、多账号管理、定时执行、电源管理等功能。

## 功能特性

### 核心功能
- **游戏内自动化操作** — 自动完成科技中心、工具台、护甲站、医疗站等设施的生产/制作/领取
- **QQ 自动登录** — 通过图像识别自动登录 QQ 账号
- **WeGame 快捷登录** — QQ 登录后自动启动 WeGame，使用当前 QQ 账号一键登录
- **多账号管理** — 在主界面管理多个 QQ 账号，支持一键切换
- **定时执行** — 支持单次或每日循环模式，可设置多个时间点自动运行
- **操作选择** — 可自由勾选需要自动执行的操作（科技中心、工具台、护甲站、医疗站）

### 高级功能
- **系统托盘运行** — 最小化至系统托盘，后台静默执行
- **电源管理** — 运行前唤醒显示器、阻止系统休眠、设置唤醒定时器
- **自动关机** — 支持设定时间自动关机
- **定时开机** — 通过 Windows 任务计划程序设置定时开机唤醒
- **开机立即运行** — 开机后自动执行一次任务，无需手动操作
- **运行前提醒** — 在执行前弹窗提醒，可取消或立即执行
- **邮件通知** — 工作流执行完成后自动发送运行结果邮件（支持 QQ 邮箱 SMTP）
- **联网时间校验** — 程序启动时进行有效期验证
- **日志记录** — 实时输出运行日志，可选保存到文件
- **单实例保护** — 禁止重复启动，重复执行自动激活已有窗口至前台

## 系统要求

- **操作系统**: Windows 10 / Windows 11
- **Python**: 3.8+
- **依赖**: 详见下方安装步骤

## 安装与运行

### 方式一：源码运行

```bash
# 克隆或下载项目后，安装依赖
pip install opencv-python numpy pyautogui psutil pywin32 pystray pillow

# 运行主程序
python main.py
```

### 方式二：打包为 exe

项目使用 PyInstaller 打包，配置文件为 `三角洲自动工具.spec`：

```bash
pip install pyinstaller
pyinstaller 三角洲自动工具.spec
```

打包后的可执行文件位于 `dist/` 目录，默认请求管理员权限（UAC）以确保进程管理和电源管理功能正常。

## 使用说明

1. **首次运行** — 程序会自动从注册表获取 WeGame 安装路径，若无则需在设置中手动指定
2. **添加 QQ 账号** — 在主界面添加 QQ 账号截图（截取 QQ 登录界面中的账号头像）
3. **配置 QQ 路径** — 在设置中指定 QQ.exe 路径
4. **选择操作** — 勾选需要自动执行的生产/制作操作
5. **执行方式**：
   - **手动执行**：点击「开始运行」立即执行一次
   - **定时执行**：在设置中启用定时执行，设置运行时间
   - **每日循环**：在设置中选择「每日循环」模式
   - **开机立即运行**：在设置 → 其他设置中开启，程序随系统启动时自动执行任务
6. **静默运行** — 勾选后程序最小化到系统托盘，完成后自动隐藏
7. **前台显示** — 程序最小化/托盘隐藏后再双击可执行文件，自动恢复前台显示
8. **托盘操作** — 双击托盘图标显示窗口，右键可打开设置或退出

### 运行流程

每轮脚本运行时，程序会按以下流程执行：

1. **清理进程** — 退出所有 QQ 和 WeGame 进程（确保干净状态）
2. **对于每个 QQ 账号**：
   - 启动 QQ 并通过图像识别完成快捷登录
   - 关闭 QQ 窗口（保留后台登录状态）
   - 启动 WeGame，点击登录按钮（使用当前 QQ 账号）
   - 查找并启动三角洲行动
   - 执行游戏内自动化操作
   - 关闭游戏、WeGame，退出 QQ 进程（不保留后台）
3. **完成** — 显示运行统计，发送邮件通知（如已启用）

### v2.6 (2026-05-18)
- 🐛 **修复（致命）**：定时任务到达指定时间后程序不执行的 bug — 调度器线程和工作线程共用同一个 `_stop_event`，用户点击「停止」或任务完成后，调度器线程也被终止，导致后续定时任务永不触发（引入独立的 `_scheduler_stop_event`，彻底分离两个线程的停止信号）
- 🐛 **修复（致命）**：定时执行在后台线程直接操作 Tkinter 控件导致静默失败 — `_execute_scheduled_run` 从调度器线程直接调用 `self.start()`，改为通过 `root.after(0, self.start)` 调度到主线程
- 🐛 **修复（严重）**：任务运行完成后未清除停止信号 — `on_finish` 未调用 `_stop_event.clear()`，导致调度器触发下一次运行时 `start()` 内部状态异常
- 🐛 **修复（严重）**：设置保存时错误停止调度器 — `apply_auto_settings_from_window` 使用 `_stop_event` 停止调度器，会误杀正在运行的工作线程
- 🐛 **修复（一般）**：运行前提醒弹窗取消后重复弹出 — 每日循环模式下已执行/已取消的时间点仍会触发提醒，增加过滤逻辑

## 配置说明

用户配置文件位于 `~/.delta_auto_settings.json`，账号列表位于 `~/.delta_auto_accounts.json`。

主要配置项：

| 配置项 | 说明 |
|--------|------|
| `wegame_path` | WeGame 启动路径 |
| `delta_path` | 三角洲启动程序路径（备用） |
| `confidence` | 图像匹配置信度（默认 0.7） |
| `run_mode` | 运行模式：单次 / 每日循环 |
| `schedule_times` | 定时执行时间列表 |
| `selected_operations` | 选中的自动操作 |
| `silent_mode` | 静默运行 |
| `wake_enabled` | 运行前唤醒电脑 |
| `auto_shutdown_enabled` | 自动关机 |
| `run_on_startup` | 开机立即运行一次程序 |
| `email_enabled` | 启用邮件通知 |
| `smtp_code` | QQ 邮箱 SMTP 授权码 |
| `sender_email` | 发送者邮箱地址 |
| `receiver_email` | 接收者邮箱地址 |
| `qq_mouse_move_distance` | QQ 账号列表鼠标下移距离（像素，默认 100） |
| `scroll_amount` | 滚动幅度（50-150，默认 100） |
| `game_launch_wait` | 游戏启动后额外等待时间（秒，0-120，默认 0） |

## 技术栈

- **GUI**: Python Tkinter / ttk
- **图像识别**: OpenCV (模板匹配)
- **自动化控制**: PyAutoGUI
- **进程管理**: psutil
- **Windows API**: pywin32 (win32gui, win32con)
- **系统托盘**: pystray + Pillow
- **打包**: PyInstaller

## 注意事项

- 程序运行时请勿遮挡屏幕，以免图像识别失败
- 图像识别依赖屏幕分辨率和显示缩放设置，建议在 1920x1080 100% 缩放下使用
- 若识别失败，可尝试在设置中降低置信度阈值
- 电源管理功能需要管理员权限
- 程序设有有效期校验（2026年7月1日），过期后将无法使用
- 邮件通知功能需在设置中配置 QQ 邮箱 SMTP 授权码（SMTP 服务器：smtp.qq.com，SSL 端口 465）
