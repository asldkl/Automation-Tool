# 三角洲行动自动化工具

基于图像识别的《三角洲行动》游戏日常自动化工具，支持 QQ 登录 + WeGame 快捷登录、多账号管理、定时执行、电源管理等功能。

## 功能特性

- **游戏内自动化** — 自动完成科技中心、工具台、护甲站、医疗站的生产/制作/领取
- **QQ 自动登录 + WeGame 快捷登录** — 多账号自动切换，完整自动化链路
- **定时执行** — 单次/每日循环，支持多个时间点，可设置运行前提醒
- **模板上传** — 在设置中可上传自定义模板图片，替换内置模板；支持内置图片预览，方便对照截图
- **一键出售** — 主流程完成后自动打开仓库，遍历售卖物品执行上架，支持降价设置、出售数量设置（适配产出数量>1的物品）
- **系统托盘** — 静默运行，后台执行任务
- **电源管理** — 唤醒电脑、自动关机、定时开机
- **邮件通知** — 执行完成后自动发送运行报告到邮箱，包含账号统计、已选操作、运行模式、一键出售结果、冷却状态
- **账号冷却管理** — 防止账号频繁执行，支持自定义冷却时间（默认8小时），含冷却状态查看和重置
- **自动领取邮箱货币** — 进入游戏后自动领取邮箱中的货币奖励
- **开机自启动** — 登录 Windows 时自动运行，可选立即执行任务
- **联网时间校验** — 启动时验证有效期
- **单实例保护** — 重复启动自动激活已有窗口

## 系统要求

- Windows 10 / 11
- Python 3.8+

## 安装与运行

```bash
pip install opencv-python numpy pyautogui psutil pywin32 pystray pillow
python main.py
```

打包为 exe：
```bash
pip install pyinstaller
pyinstaller 三角洲自动工具.spec
```

## 使用说明

1. 添加 QQ 账号截图，配置 QQ/WeGame 路径
2. 勾选需要自动执行的操作
3. 点击「开始运行」手动执行，或在设置中启用定时执行
4. 在「图像识别设置」中点击「上传模板图片」可替换内置模板，点击「预览」可查看当前模板图片，点击「恢复默认」可还原
   - 上传后自动生效，用户自定义模板始终优先于内置模板
5. 在模板上传向导底部可管理售卖物品图片，同一物品可重复添加以匹配产出数量
6. 在「自动任务设置」中可启用「一键出售」并设置降价次数（0-5次）、出售数量（1-99）
7. 在模板上传向导底部点击「出售测试」可单独测试出售流程（需先回到游戏仓库界面）

### QQ 截图优化建议

- 添加 QQ 账号截图后，右键选择「裁剪截图」框选包含头像+名称+QQ号的区域
- 头像轮廓、名称文字、QQ数字三个特征组合可精确区分不同账号
- 可使用「测试截图识别」验证匹配度，同时查看灰度匹配和边缘匹配结果
- 程序会自动尝试多尺度复合匹配（0.7x-1.3x 缩放），适配不同分辨率

### 一键出售说明

1. 出售相关模板（仓库、出售、上架、降价、确认上架）已内置在 `picture/One_Click_Sell/` 目录，可在模板上传向导中点击「预览」查看
2. 在模板上传向导底部的「售卖物品」区域，点击「添加物品」上传要出售的物品截图；同一物品可重复添加以匹配产出数量（如产出3个弹药则添加3次）
3. 截图规范：在仓库界面截取物品图标，确保物品图标清晰、无遮挡
4. 在设置中启用「主流程完成后执行一键售卖」并设置降价次数、出售数量
5. 主流程（制造/生产）完成后会自动按 Esc 回到主界面，然后执行出售流程
6. 出售流程：打开仓库 → 逐个识别物品 → 出售 → 上架 → 降价（按设置次数）→ 确认上架
7. 也可在模板上传向导中点击「出售测试」按钮单独测试出售流程（测试前请先回到游戏仓库界面）
8. 出售物品匹配置信度可在设置中调节（0.40-0.80），默认 0.55，较低值更宽松、较高值更严格

### 运行流程

清理进程 → 逐个账号：启动 QQ 登录 → 关闭 QQ → 启动 WeGame 快捷登录 → 进入游戏执行操作 → 关闭游戏和 WeGame → 完成

## 配置说明

用户配置：`~/.delta_auto_settings.json`，账号列表：`~/.delta_auto_accounts.json`，自定义模板：`~/.delta_auto_templates/`，冷却数据：`~/.delta_auto_cooldown.json`

| 配置项 | 说明 |
|--------|------|
| `wegame_path` / `qq_path` | WeGame / QQ 启动路径 |
| `confidence` | 图像匹配置信度（默认 0.7） |
| `run_mode` | 运行模式：单次 / 每日循环 |
| `schedule_times` | 定时执行时间列表 |
| `selected_operations` | 选中的自动操作 |
| `silent_mode` | 静默运行（托盘） |
| `wake_enabled` | 运行前唤醒电脑 |
| `auto_shutdown_enabled` | 自动关机 |
| `run_on_startup` | 开机立即运行 |
| `email_enabled` / `smtp_code` | 邮件通知配置 |
| `qq_mouse_move_distance` | QQ 账号列表鼠标下移距离 |
| `scroll_amount` | 滚动幅度（50-150） |
| `game_launch_wait` | 游戏启动等待时间（秒） |
| `enable_sell_after_run` | 主流程后执行一键出售 |
| `sell_discount_times` | 降价次数（0-5） |
| `sell_confidence` | 出售物品匹配置信度（0.40-0.80） |
| `sell_quantity` | 每个物品出售次数（1-99，适配产出数量>1的物品） |
| `enable_cooldown` | 启用账号冷却（默认8小时） |
| `cooldown_delay_minutes` | 账号间隔时间（0-5分钟） |
| `cooldown_run_immediately` | 冷却完立即运行（与定时执行互斥） |
| `cooldown_email_enabled` | 冷却到期邮件提醒 |
| `enable_email_currency` | 启用自动领取邮箱货币 |

- 程序目录路径支持中文等非 ASCII 字符
