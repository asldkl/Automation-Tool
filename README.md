# 三角洲行动自动化工具

基于图像识别的《三角洲行动》游戏日常自动化工具，支持 WeGame 账号登录、多账号管理、冷却执行、资产监测等功能。

## 功能特性

- **游戏内自动化** — 自动完成科技中心、工具台、护甲站、医疗站的生产/制作/领取
- **WeGame 直接登录** — 使用 Interception 驱动级键盘输入在 WeGame 界面直接输入账号密码登录（WeGame 支持多账号单独登录）
- **冷却执行** — 账号冷却始终开启，冷却到期自动运行，默认8小时；双击主界面「下次运行时间」列可直接设置自定义冷却时间（如 8H 30M），含冷却状态查看、重置和暂停/恢复
- **模板上传** — 在设置中可上传自定义模板图片，替换内置模板；支持内置图片预览，方便对照截图
- **一键出售** — 主流程完成后自动打开仓库，遍历售卖物品执行上架，支持降价设置、出售数量设置（适配产出数量>1的物品）；未配置售卖物品时自动跳过售卖
- **系统托盘** — 静默运行，后台执行任务
- **自动关机** — 运行完成后延迟关机（0-5分钟），手动终止时不执行
- **邮件通知** — 执行完成后自动发送运行报告到邮箱，包含账号统计、一键出售结果、冷却状态、每个账号资产数、本轮最先/最后运行时间；手动终止时不发送
- **暂停账号** — 右键账号可暂停，暂停后运行时自动跳过该账号，支持恢复；**连续失败 2 次自动暂停**（跨轮累计，列表标黄，不弹窗），手动暂停为红色
- **自动领取邮箱货币** — 进入游戏后自动领取邮箱中的货币奖励
- **OCR 文字识别** — 支持对屏幕指定区域进行文字识别，可作为图像匹配的替代方案，支持 OCR 降级开关、全局文本配置、调试日志
- **资产识别** — 进入游戏后自动识别并显示账号资产数值
- **资产监测** — SQLite 持久化资产记录，支持自定义天数统计资产变化，正数绿色负数红色
- **皮肤抢购** — 图片识别监控购买按钮，找到后自动点击并确认购买，超时自动停止；在设置→实验功能中打开
- **账号信息管理** — 右键账号可设置游戏账号、密码、备注等信息，密码默认隐藏可切换显示
- **账号状态颜色** — 冷却中账号蓝色、可运行账号绿色、已暂停账号红色，直观区分账号状态
- **账号列表分隔线** — 每个账号下方显示分隔线，便于视觉区分
- **鼠标移动优化** — 贝塞尔曲线路径 + Smoothstep 缓动算法，模拟自然鼠标移动轨迹
- **开机自启动** — 登录 Windows 时自动运行
- **单实例保护** — 重复启动自动激活已有窗口
- **机器指纹绑定** — 通过硬盘+主板序列号生成唯一指纹，防止程序被滥用
- **远程有效期控制** — 有效期由服务器端统一管理，启动时和每天首次运行时双重校验
- **账号状态实时同步** — 运行时通过心跳机制实时推送账号状态到云端服务器
- **冷却定时任务兜底** — 冷却到期时通过 Windows 任务计划程序自动启动程序，即使程序未运行或监听线程异常也能稳定触发，支持开关控制
- **日志按日期分文件夹** — 每次运行生成独立日志文件，按「日期/日志/运行时间.log」结构存储；截图保存在「日期/图片/」，方便分辨每次运行结果
- **自动清理日志/备份** — 默认保留最近 3 天，启动时与任务完成后自动清理过期的日志/截图日期文件夹和账号数据备份（设置→目录及数据可修改保留天数，0=不清理）
- **错误屏幕文字诊断** — 账号运行失败跳过时自动 OCR 识别当前屏幕文字输出到日志，便于根据关键词定位错误原因
- **模板置信度测试** — 模板设置窗口中集成置信度测试按钮，点击即可查看该模板在屏幕上的匹配置信度
- **新任务自动取消关机** — 开始新任务时自动取消待执行的延迟关机计划，避免冷却触发新任务时误关机
- **Caps Lock 保护** — 输入账号密码前自动检测并关闭 Caps Lock，避免密码被大写锁定输入错误
- **冷却数据备份** — cooldown.json 保存时自动备份（.bak + 带时间戳历史备份），文件损坏/丢失/崩溃后自动从备份恢复（.bak → 时间戳备份）；文件损坏且无可用备份时拒绝用空数据覆盖（防止冷却与暂停状态被抹掉）；每个账号结束立即写盘，任务结束兜底保存；暂停账号保留冷却进度（恢复暂停后仍处于冷却中直到到期）
- **全体延时+ / 冷却缩减-** — 主界面一键为所有冷却中的账号延长或缩减 30 分钟冷却，不影响暂停账号；缩减后到期的账号直接变为可运行
- **账号数据导入导出** — 设置→其他设置页可一键导入/导出账号列表、密码备注、资产及历史记录；支持自动备份（0-3天间隔），启动时与任务完成后按间隔自动备份账号+冷却+配置到「目录及数据/账号数据备份/」，崩溃/蓝屏导致数据丢失后可从此恢复
- **快速启动验证** — 机器指纹后台加载 + 缓存，启动不卡界面，WMI 查询异常时也能快速通过
- **点击拟人抖动** — 游戏内操作点击位置随机偏移（默认≤5px，可在设置→全局设置中开关/调节），减少机械化痕迹
- **自动缩到托盘** — 运行自动化时主窗口自动隐藏到系统托盘，不遮挡游戏画面，运行完成自动恢复
- **日志遮罩** — 透明日志叠加层（PyQt6），加粗分级彩色日志，鼠标穿透不影响游戏；顶部固定显示「正在运行第x个账号 + 运行时长」，空闲显示「未运行」；默认开启，可在实验功能里关闭或点「更换角落」逆时针旋转（左下→右下→右上→左上，位置记忆）
- **自定义操作** — 设置→自动任务中配置「找图→单击」步骤序列，每个账号主流程完成、游戏回到主界面后自动逐步骤执行，可自行批量操作；某步找不到图则跳到下一个账号，点击可选用拟人抖动

## Interception 驱动级键盘输入

本工具使用 [Interception](https://github.com/oblitum/Interception) 驱动实现 WeGame 登录界面中账号密码的可靠输入。

### 驱动安装状态

Interception 驱动已安装在本机，可在正常模式（测试签名关闭）下工作，不需要开启 Windows 测试模式。
- 驱动文件：`C:\Windows\System32\drivers\keyboard.sys`（伪装为系统键盘驱动）
- 服务名称：`keyboard`（内核驱动，手动启动）
- DLL 依赖：`interception.dll`（已包含在项目目录中，打包时自动嵌入）

### 在新电脑上安装驱动

如需在新电脑部署，有两种方式：

**方式一：使用安装程序（推荐）**
运行安装程序时勾选「安装 Interception 键盘驱动」即可自动安装。

**方式二：手动安装**
以管理员身份运行安装目录下的 `install_interception.bat`，然后重启电脑。

验证驱动状态：
```bash
sc query keyboard
```
输出应显示 `RUNNING`。注意：服务名为 `keyboard`（非 `interception`）。

### 设备号说明

Interception 驱动中设备 1 是只读中转设备，真实键盘设备从 2 开始。
程序会自动检测可写入的设备号，无需手动配置。

## 使用说明

1. 点击「添加账号」，在弹出的账号信息设置窗口中填写游戏账号（必填）、密码（必填）、备注等信息
2. 配置 WeGame 路径
3. 勾选需要自动执行的操作
4. 点击「开始运行」手动执行；账号冷却默认开启，冷却到期后自动运行（双击「下次运行时间」列可设置自定义冷却时间）
5. 在「图像识别设置」中点击「上传模板图片」可替换内置模板，点击「预览」可查看当前模板图片，点击「恢复默认」可还原
   - 上传后自动生效，用户自定义模板始终优先于内置模板
6. 在「设置 → 售卖物品」中管理售卖物品图片，同一物品可重复添加以匹配产出数量
7. 在「自动任务设置」中可启用「一键出售」并设置降价次数（0-5次）、出售数量（1-99）
8. 在「设置 → 售卖物品」中点击「出售测试」可单独测试出售流程（需先回到游戏仓库界面）

### 一键出售说明

1. 出售相关模板（仓库、出售、上架、降价、确认上架）已内置在 `picture/One_Click_Sell/` 目录，可在模板上传向导中点击「预览」查看
2. 在「设置 → 售卖物品」页面，点击「添加物品」上传要出售的物品截图；同一物品可重复添加以匹配产出数量（如产出3个弹药则添加3次）
3. 截图规范：在仓库界面截取物品图标，确保物品图标清晰、无遮挡
4. 在设置中启用「主流程完成后执行一键售卖」并设置降价次数、出售数量
5. 主流程（制造/生产）完成后会自动按 Esc 回到主界面，然后执行出售流程
6. 出售流程：打开仓库 → 逐个识别物品 → 出售 → 上架 → 降价（按设置次数）→ 确认上架
7. 也可在「设置 → 售卖物品」中点击「出售测试」按钮单独测试出售流程（测试前请先回到游戏仓库界面）
8. 出售物品匹配置信度可在设置中调节（0.40-0.80），默认 0.55，较低值更宽松、较高值更严格
9. 若「售卖物品」列表为空（未添加任何物品），则自动跳过整个出售流程（不会打开仓库）

### 自定义操作说明

1. 在「设置 → 自动任务」页最下方点击「配置自定义操作」打开配置窗口
2. 步骤按**「份」（批次）组织**：顶部份下拉切换编辑哪一份，可「＋ 新增份 / 删除份 / 份设置」，每份可设不同运行次数
3. 支持十种步骤（顶部「＋ 添加步骤」菜单选择，编辑框内类型下拉为中文）：
   - **找图点击**（默认）：编辑框内可框选/导入图片，匹配后点击
   - **坐标点击**：填 X/Y 或「屏幕取点」；**鼠标拖拽**：起点→终点；**鼠标滚轮**：上下格数
   - **OCR点击**：填文字，识别后点击；**键盘输入**：按键/组合键（esc、Enter、ctrl+a 等）或输入文本（中文等非 ASCII 用剪贴板粘贴；游戏内用 SendInput，Interception 驱动仅用于登录输入账号密码）
   - **多图点击**：一个步骤配多张图，按顺序点第一张找到的（处理按钮多种状态）
   - **截图保存**：截图保存到 设置→全局设置→截图保存目录/日期/图片/账号名_时间.png（如 8月11日/图片）
   - **条件跳转**：找图/OCR 探测，满足则跳转到指定步骤；**跳转**：无条件跳转（配合实现循环/重试）
4. 双击或右键步骤可修改属性（类型在编辑框下拉里切换）、**运行本步骤**、上移/下移/删除；步骤默认命名为「类型名+序号」
5. 账号主流程完成后**所有份都执行**，每份各自受「份设置」里的频率限制（X次/Y天，0=不限，**按自然日计算**：如每天1次即同一自然日最多执行1次；**仅成功完成的工作流计入次数**），超限的份跳过、其他份照常
6. 某一步找不到目标，则中止**该份**（其他份继续）；底部「设置」窗口含主流程后自动执行、点击随机偏移
7. 窗口左下角「▶ 运行测试 / ⏹ 停止」试运行当前份，右下角「保存步骤」保存配置；窗口大小位置自动记忆

### 运行流程

清理进程（WeGame/三角洲） → 逐个账号：
1. 打开 WeGame → 图像识别双击账号选择框（左偏 15px）→ 删除旧账号 → Interception 驱动级键盘输入账号 → 点击密码框 → Interception 输入密码 → 点击登录
2. 找到三角洲图标 → 启动游戏 → 进入烽火地带 → 进入特勤处 → 第一次资产识别 → 执行操作（设施/出售/邮箱）→ 第二次资产识别 → 关闭游戏和 WeGame → 完成

## 配置说明

用户数据统一存储在 `%APPDATA%\DeltaAutoTool\` 目录下：
- `settings.json` — 用户设置
- `accounts.json` — 账号列表（含备份文件 accounts.json.bak）
- `templates/` — 用户自定义模板
- `sell_items/` — 售卖物品图片和元数据
- `cooldown.json` — 冷却数据（含备份文件 cooldown.json.bak，损坏/丢失自动恢复）
- `assets.db` — 资产记录 SQLite 数据库
- `error.log` — 程序异常日志（启动失败时生成）

日志、截图、账号数据备份（启用 `log_save_path` 时，设置里名为「目录及数据」）按日期分文件夹存储，日期文件夹内再分「日志」「图片」子文件夹，另有独立的「账号数据备份」文件夹：
```
目录及数据/
├── 8月11日/
│   ├── 日志/                 ← 运行日志
│   │   ├── startup.log      ← 程序启动 ~ 第一次运行前
│   │   ├── 14-30-25.log     ← 第一次运行
│   │   └── 20-15-00.log     ← 第二次运行
│   └── 图片/                 ← 自定义操作「截图保存」步骤
│       └── 账号名_时间.png
├── 8月12日/
│   └── 日志/
│       └── 09-00-30.log     ← 新的一天
└── 账号数据备份/            ← 账号数据自动备份（按间隔天数）
    ├── accounts.json.时间戳.bak
    ├── cooldown.json.时间戳.bak
    └── settings.json.时间戳.bak
```

| 配置项 | 说明 |
|--------|------|
| `wegame_path` | WeGame 启动路径 |
| `confidence` | 图像匹配置信度（默认 0.7） |
| `account_backup_days` | 账号数据自动备份间隔（天，0=关闭，默认0） |
| `log_retention_days` | 日志/备份保留天数（0=不清理，默认3） |
| `cooldown_hours` | 冷却小时数 |
| `selected_operations` | 选中的自动操作 |
| `auto_shutdown_enabled` | 自动关机 |
| `email_enabled` / `smtp_code` | 邮件通知配置 |
| `game_launch_wait` | 游戏启动等待时间（秒） |
| `enable_sell_after_run` | 主流程后执行一键出售 |
| `sell_discount_times` | 降价次数（0-5） |
| `sell_confidence` | 出售物品匹配置信度（0.40-0.80） |
| `sell_quantity` | 每个物品出售次数（1-99，适配产出数量>1的物品） |
| `cooldown_run_immediately` | 冷却完立即运行 |
| `cooldown_scheduled_task_enabled` | 冷却到期定时任务兜底（默认开启） |
| `restart_on_interception_fail` | Interception 驱动失败时自动重启电脑（默认关闭） |
| `enable_email_currency` | 启用自动领取邮箱货币 |
| `post_run_shutdown_delay` | 运行完成后延迟关机（0-5分钟，0=不关机） |
| `server_url` | 服务器地址（用于机器指纹验证和心跳同步） |
| `client_key` | 客户端密钥（用于服务器通信认证） |
| `enable_ocr` | 启用 OCR 文字识别 |
| `ocr_configs` | OCR 配置（区域、目标文本、置信度） |
| `global_ocr_enabled` | 启用全局 OCR 区域 |
| `global_ocr_texts` | 全局 OCR 文本配置 |
| `global_ocr_confidence` | 全局 OCR 默认置信度（默认 0.55） |
| `ocr_downgrade_enabled` | OCR 超时降级到图片匹配（默认启用） |
| `enable_asset_recognition` | 启用资产识别 |
| `enable_custom_ops` | 主流程完成后自动执行自定义操作（默认关闭） |
| `custom_ops_confidence` | 自定义操作默认找图置信度 |
| `custom_ops_timeout` | 自定义操作默认找图超时（秒） |
| `custom_ops_pause` | 自定义操作默认点击后停顿（秒） |
| `custom_ops_jitter` | 自定义操作点击是否受随机偏移影响（默认关闭，复用 click_jitter_max） |
| `asset_region` | 资产识别屏幕区域 [x, y, w, h] |
| `asset_ocr_confidence` | 资产识别置信度 |

## 技术栈

Tkinter / OpenCV / PyAutoGUI / psutil / pywin32 / pystray+Pillow / RapidOCR / PyInstaller / Nuitka

## 注意事项

- 运行时请勿遮挡屏幕
- 内置模板基于 2560×1440（2K）+ 游戏 1440×900 制作，其他分辨率识别失败可在设置中降低置信度或上传自定义模板
- 电源管理需管理员权限
- 程序目录路径支持中文等非 ASCII 字符
- 首次运行和每天首次执行任务时需要联网进行机器指纹验证和有效期校验
- 程序绑定机器指纹，防止未经授权使用，验证失败时弹窗显示本机指纹
