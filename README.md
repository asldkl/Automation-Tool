# 三角洲行动自动化工具

基于图像识别的《三角洲行动》游戏日常自动化工具，支持 WeGame 账号登录、多账号管理、冷却执行、资产监测等功能。

## 功能特性

- **游戏内自动化** — 自动完成科技中心、工具台、护甲站、医疗站的生产/制作/领取
- **WeGame 直接登录** — 使用 Interception 驱动级键盘输入在 WeGame 界面直接输入账号密码登录，绕开 WeGame 10 账号限制
- **冷却执行** — 冷却到期自动运行，支持自定义冷却时间（默认8小时），含冷却状态查看、重置和暂停/恢复
- **模板上传** — 在设置中可上传自定义模板图片，替换内置模板；支持内置图片预览，方便对照截图
- **一键出售** — 主流程完成后自动打开仓库，遍历售卖物品执行上架，支持降价设置、出售数量设置（适配产出数量>1的物品）
- **系统托盘** — 静默运行，后台执行任务
- **自动关机** — 运行完成后延迟关机（0-5分钟），手动终止时不执行
- **邮件通知** — 执行完成后自动发送运行报告到邮箱，包含账号统计、一键出售结果、冷却状态、每个账号资产数；手动终止时不发送
- **暂停账号** — 右键账号可暂停，暂停后运行时自动跳过该账号，支持恢复
- **自动领取邮箱货币** — 进入游戏后自动领取邮箱中的货币奖励
- **OCR 文字识别** — 支持对屏幕指定区域进行文字识别，可作为图像匹配的替代方案，支持 OCR 降级开关、全局文本配置、调试日志
- **资产识别** — 进入游戏后自动识别并显示账号资产数值
- **资产监测** — SQLite 持久化资产记录，支持自定义天数统计资产变化，正数绿色负数红色
- **皮肤抢购** — 图片识别监控购买按钮，找到后自动点击并确认购买，超时自动停止
- **账号信息管理** — 右键账号可设置游戏账号、密码、备注等信息，密码默认隐藏可切换显示
- **账号状态颜色** — 冷却中账号蓝色、可运行账号绿色、已暂停账号红色，直观区分账号状态
- **账号列表分隔线** — 每个账号下方显示分隔线，便于视觉区分
- **鼠标移动优化** — 贝塞尔曲线路径 + Smoothstep 缓动算法，模拟自然鼠标移动轨迹
- **开机自启动** — 登录 Windows 时自动运行
- **单实例保护** — 重复启动自动激活已有窗口
- **机器指纹绑定** — 通过硬盘+主板序列号生成唯一指纹，防止程序被复制到其他电脑使用
- **远程有效期控制** — 有效期由服务器端统一管理，启动时和每天首次运行时双重校验
- **账号状态实时同步** — 运行时通过心跳机制实时推送账号状态到云端服务器
- **冷却定时任务兜底** — 冷却到期时通过 Windows 任务计划程序自动启动程序，即使程序未运行或监听线程异常也能稳定触发，支持开关控制
- **日志按日期分文件夹** — 每次运行生成独立日志文件，按「日期文件夹/运行时间.log」结构存储，方便分辨每次运行结果
- **错误屏幕文字诊断** — 账号运行失败跳过时自动 OCR 识别当前屏幕文字输出到日志，便于根据关键词定位错误原因
- **模板置信度测试** — 模板设置窗口中集成置信度测试按钮，点击即可查看该模板在屏幕上的匹配置信度
- **新任务自动取消关机** — 开始新任务时自动取消待执行的延迟关机计划，避免冷却触发新任务时误关机

## 系统要求

- Windows 10 / 11
- Python 3.8+

## Interception 驱动级键盘输入

本工具使用 [Interception](https://github.com/oblitum/Interception) 驱动实现 WeGame 登录时的账号密码输入，绕开 WeGame 10 账号限制和 QQ 同 IP 验证码。

### 驱动安装状态

Interception 驱动已安装在本机，可在正常模式（测试签名关闭）下工作，不需要开启 Windows 测试模式。
- 驱动文件：`C:\Windows\System32\drivers\keyboard.sys`（伪装为系统键盘驱动）
- 服务名称：`keyboard`（内核驱动，手动启动）
- DLL 依赖：`interception.dll`（已包含在项目目录中，打包时自动嵌入）

### 在新电脑上安装驱动

如需在新电脑部署，有两种方式：

**方式一：使用安装程序（推荐）**
运行安装程序时勾选「安装 Interception 键盘驱动」即可自动安装。

**方式二：手动安装**
以管理员身份运行安装目录下的 `install_interception.bat`，然后重启电脑。

验证驱动状态：
```bash
sc query keyboard
```
输出应显示 `RUNNING`。注意：服务名为 `keyboard`（非 `interception`）。

### 设备号说明

Interception 驱动中设备 1 是只读中转设备，真实键盘设备从 2 开始。
程序会自动检测可写入的设备号，无需手动配置。

## 使用说明

1. 点击「添加账号」，在弹出的账号信息设置窗口中填写游戏账号（必填）、密码（必填）、备注等信息
2. 配置 WeGame 路径
3. 勾选需要自动执行的操作
4. 点击「开始运行」手动执行，或在设置中启用冷却执行（冷却到期自动运行）
5. 在「图像识别设置」中点击「上传模板图片」可替换内置模板，点击「预览」可查看当前模板图片，点击「恢复默认」可还原
   - 上传后自动生效，用户自定义模板始终优先于内置模板
6. 在「设置 → 售卖物品」中管理售卖物品图片，同一物品可重复添加以匹配产出数量
7. 在「自动任务设置」中可启用「一键出售」并设置降价次数（0-5次）、出售数量（1-99）
8. 在「设置 → 售卖物品」中点击「出售测试」可单独测试出售流程（需先回到游戏仓库界面）

### 一键出售说明

1. 出售相关模板（仓库、出售、上架、降价、确认上架）已内置在 `picture/One_Click_Sell/` 目录，可在模板上传向导中点击「预览」查看
2. 在「设置 → 售卖物品」页面，点击「添加物品」上传要出售的物品截图；同一物品可重复添加以匹配产出数量（如产出3个弹药则添加3次）
3. 截图规范：在仓库界面截取物品图标，确保物品图标清晰、无遮挡
4. 在设置中启用「主流程完成后执行一键售卖」并设置降价次数、出售数量
5. 主流程（制造/生产）完成后会自动按 Esc 回到主界面，然后执行出售流程
6. 出售流程：打开仓库 → 逐个识别物品 → 出售 → 上架 → 降价（按设置次数）→ 确认上架
7. 也可在「设置 → 售卖物品」中点击「出售测试」按钮单独测试出售流程（测试前请先回到游戏仓库界面）
8. 出售物品匹配置信度可在设置中调节（0.40-0.80），默认 0.55，较低值更宽松、较高值更严格

### 运行流程

清理进程（WeGame/三角洲） → 逐个账号：
1. 打开 WeGame → 图像识别双击账号选择框（左偏 15px）→ 删除旧账号 → Interception 驱动级键盘输入账号 → 点击密码框 → Interception 输入密码 → 点击登录
2. 找到三角洲图标 → 启动游戏 → 进入烽火地带 → 进入特勤处 → 第一次资产识别 → 执行操作（设施/出售/邮箱）→ 第二次资产识别 → 关闭游戏和 WeGame → 完成

## 配置说明

用户数据统一存储在 `%APPDATA%\DeltaAutoTool\` 目录下：
- `settings.json` — 用户设置
- `accounts.json` — 账号列表（含备份文件 accounts.json.bak）
- `templates/` — 用户自定义模板
- `sell_items/` — 售卖物品图片和元数据
- `cooldown.json` — 冷却数据
- `assets.db` — 资产记录 SQLite 数据库
- `error.log` — 程序异常日志（启动失败时生成）

日志文件（启用 `log_save_path` 时）按日期分文件夹存储：
```
日志目录/
├── 2026-07-24/
│   ├── startup.log          ← 程序启动 ~ 第一次运行前
│   ├── 14-30-25.log         ← 第一次运行
│   └── 20-15-00.log         ← 第二次运行
└── 2026-07-25/
    └── 09-00-30.log         ← 新的一天
```

| `sell_discount_times` | 降价次数（0-5） |
| `sell_confidence` | 出售物品匹配置信度（0.40-0.80） |
| `sell_quantity` | 每个物品出售次数（1-99，适配产出数量>1的物品） |

## 技术栈

Tkinter / OpenCV / PyAutoGUI / psutil / pywin32 / pystray+Pillow / RapidOCR / PyInstaller / Nuitka

## 注意事项

- 运行时请勿遮挡屏幕
- 内置模板基于 2560×1440（2K）+ 游戏 1440×900 制作，其他分辨率识别失败可在设置中降低置信度或上传自定义模板
- 电源管理需管理员权限
- 有效期至 2026 年 8 月 1 日（由服务器端统一控制）
- 程序目录路径支持中文等非 ASCII 字符
- 首次运行和每天首次执行任务时需要联网进行机器指纹验证和有效期校验
- 程序绑定机器指纹，复制到其他电脑无法运行，验证失败时弹窗显示本机指纹
- 服务器不可用时程序无法运行，请确保服务器在线
