================================================================================
                    三角洲行动自动化工具 - 使用说明书
================================================================================

版本: v1.3.4
更新日期: 2026-07-15

本工具是基于图像识别的《三角洲行动》游戏日常自动化工具，帮你自动完成
特勤处制造/生产/领取、邮箱货币领取、一键出售等重复操作。

================================================================================
1. 安装步骤
================================================================================

1. 运行安装程序「三角洲行动自动化工具_安装程序.exe」
2. 如提示需要管理员权限，点击「是」
3. 安装时建议勾选「安装 Interception 键盘驱动」（WeGame 登录需要）
4. 安装完成后勾选「启动程序」
5. 首次启动会自动创建配置目录（%APPDATA%\DeltaAutoTool\）

注意：如果安装了 Interception 驱动，安装程序会提示重启电脑，
建议立即重启，否则驱动无法生效。

================================================================================
2. 快速开始
================================================================================

----- 第一步：添加账号 -----

1. 在主界面点击「添加账号」
2. 在弹出的窗口中填写：
   - QQ账号（必填）
   - QQ密码（必填，用于 WeGame 登录）
   - 备注（可选）
3. 点击保存

----- 第二步：检查配置 -----

1. 点击主界面「设置」按钮
2. 在「全局设置」中确认：
   - WeGame 路径已自动检测（或手动填写）
   - 图像匹配置信度（默认 0.7，识别不到可适当降低）
3. 勾选需要自动执行的操作（技术中心、工作台等）
4. 根据需要开启「一键出售」「邮箱货币」等功能

----- 第三步：运行 -----

1. 确保游戏已更新到最新版本
2. 确保电脑分辨率 1920×1080，缩放 100%（推荐）
3. 点击主界面「开始运行」
4. 程序会自动完成：登录账号 → 进入游戏 → 特勤处 → 制造/收取/领取 → 出售

================================================================================
3. 功能介绍
================================================================================

----- 多账号管理 -----

- 添加/删除账号，支持排序
- 每个账号可设置QQ账号、密码、备注
- 右键账号可暂停（暂停后运行时会自动跳过）
- 账号状态颜色：蓝色（冷却中）、绿色（可运行）、红色（已暂停）

----- 冷却执行 -----

- 在设置中开启「冷却执行」
- 每个账号运行完后自动冷却（默认8小时）
- 冷却到期后自动运行
- 支持查看冷却状态、重置冷却、手动设置冷却时间

----- 一键出售 -----

- 主流程完成后自动打开仓库，逐个出售物品
- 支持降价设置（0-5次）
- 支持数量设置（适配产出多个物品的情况）
- 在「设置→售卖物品」中管理要出售的物品图片

----- 邮箱货币 -----

- 进入游戏后自动打开邮箱
- 进入交易中心领取货币奖励

----- 资产识别与监测 -----

- 进入游戏后自动识别账号资产数值
- 资产记录持久化到 SQLite 数据库
- 可查看指定天数内的资产变化

----- 皮肤抢购 -----

- 在设置中打开「皮肤抢购」窗口
- 设置搜索区域和购买按钮图片
- 程序自动在区域内查找购买按钮，找到后自动点击购买
- 确认购买 3 秒后退出，刷新页面继续监控
- 超时自动停止（默认30分钟）

================================================================================
4. 模板上传
================================================================================

在「设置→全局设置→模板上传向导」中：
1. 所有模板按主流程顺序排列（登录→导航→设施→制造→邮箱→出售）
2. 点击「上传」替换内置模板图片
3. 每次上传一张，上传后自动生效
4. 支持预览当前模板和恢复默认

截图规范：
- 建议 PNG 格式
- 保持与游戏内实际显示一致
- 确保图片清晰、无遮挡

================================================================================
5. WeGame 登录说明
================================================================================

本工具使用 Interception 驱动级键盘输入，在 WeGame 登录界面直接输入
账号密码，绕开 WeGame 10 账号限制。

自动登录流程：
1. 程序打开 WeGame
2. 自动选择账号输入框，清空旧内容
3. 驱动级输入账号
4. 自动点击密码输入框，输入密码
5. 点击登录确认
6. 找到三角洲游戏图标，启动游戏

如果 Interception 驱动未安装或不可用：
- 安装程序时会提示安装驱动
- 也可以手动运行安装目录下的 install_interception.bat（管理员身份）
- 安装后需重启电脑

驱动验证方法（管理员 CMD）：
    sc query keyboard
    如果显示 RUNNING 则表示驱动正常工作

================================================================================
6. 设置说明
================================================================================

常用设置项：

  图像匹配置信度    0.7（建议范围 0.5-0.9，越低越容易匹配到图片）
  WeGame 路径      自动检测，一般无需手动填写
  冷却小时数        默认 8 小时
  一键出售置信度    0.55（独立于图像识别置信度）
  账号间隔时间      0-5 分钟（每个账号运行完后等待时间）

所有设置在「设置」窗口中修改，修改后自动保存。

================================================================================
7. 目录和数据文件
================================================================================

程序安装目录（默认）：
    C:\Program Files\三角洲行动自动化工具\

用户数据目录：
    %APPDATA%\DeltaAutoTool\
    ├── settings.json          # 用户配置
    ├── accounts.json          # 账号列表
    ├── cooldown.json          # 冷却数据
    ├── assets.db              # 资产记录
    ├── templates/             # 用户自定义模板
    └── sell_items/            # 售卖物品图片

日志文件：
    %APPDATA%\DeltaAutoTool\error.log  （程序异常时自动生成）

================================================================================
8. 常见问题
================================================================================

Q: 程序无法启动？
A:
  1. 检查是否以管理员身份运行
  2. 检查杀毒软件是否拦截
  3. 查看 %APPDATA%\DeltaAutoTool\error.log

Q: 图像识别失败？
A:
  1. 确认游戏分辨率为 1920×1080，缩放 100%
  2. 在设置中降低置信度（如从 0.7 降到 0.6）
  3. 在模板上传向导中查看并重新截图上传

Q: WeGame 登录失败？
A:
  1. 确认已安装 Interception 驱动：sc query keyboard
  2. 确认 WeGame 路径设置正确
  3. 检查账号密码是否正确

Q: 皮肤抢购不工作？
A:
  1. 确认已设置搜索区域
  2. 确认已选择购买按钮图片
  3. 点击「测试搜索」验证图片是否能找到
