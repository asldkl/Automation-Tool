================================================================================
                    三角洲行动自动化工具 - 使用说明书
================================================================================

版本: 6.09.26
更新日期: 2026-09-26

本工具是基于图像识别的《三角洲行动》游戏日常自动化工具，帮你自动完成
特勤处制造/生产/领取、邮箱货币领取、一键出售等重复操作。

================================================================================
1. 安装步骤
================================================================================

1. 运行安装程序「三角洲行动自动化工具_安装程序.exe」
2. 如提示需要管理员权限，点击「是」
3. 安装时建议勾选「安装 Interception 键盘驱动」（WeGame 登录需要）
4. 安装完成后勾选「启动程序」
5. 首次启动会自动创建配置目录（%APPDATA%\DeltaAutoTool\）

注意：如果安装了 Interception 驱动，安装程序会提示重启电脑，
建议立即重启，否则驱动无法生效。

================================================================================
2. 快速开始
================================================================================

----- 第一步：添加账号 -----

1. 在主界面点击「添加账号」
2. 在弹出的窗口中填写：
   - QQ账号（必填）
   - QQ密码（必填，用于 WeGame 登录）
   - 备注（可选）
3. 点击保存

----- 第二步：检查配置 -----

1. 点击主界面「设置」按钮
2. 在「全局设置」中确认：
   - WeGame 路径已自动检测（或手动填写）
   - 图像匹配置信度（默认 0.7，识别不到可适当降低）
3. 勾选需要自动执行的操作（技术中心、工作台等）
4. 根据需要开启「一键出售」「邮箱货币」等功能

----- 第三步：运行 -----

1. 确保游戏已更新到最新版本
2. 模板基于 2K 分辨率（2560×1440）下制作，建议使用 2K 分辨率运行；若识别失败可在设置中降低置信度或上传自定义模板
3. 点击主界面「开始运行」
4. 程序会自动完成：登录账号 → 进入游戏 →（观察账号先识别「观察状态入口」）→ 烽火地带 → 特勤处 → 制造/收取/领取 → 出售

================================================================================
3. 功能介绍
================================================================================

----- 多账号管理 -----

- 添加/删除账号，支持排序
- 每个账号可设置QQ账号、密码、备注
- 右键账号可暂停（暂停后运行时会自动跳过）；暂停期间保留冷却进度，恢复暂停后仍按原冷却时间运行
- 账号状态颜色：蓝色（冷却中）、绿色（可运行）、红色（已暂停）、**黄色（连续失败 2 次自动暂停，不弹窗，手动恢复后重新计数）**
- 双击操作：双击「现有资产」列查看资产记录；双击「下次运行时间」列设置冷却；双击「名称/备注」列设置账号信息（底部提示每 60 秒轮换）

----- 观察状态 -----

- 账号信息设置窗口中「观察状态」按钮可一键切换账号进入/退出观察状态（点击立即生效，无需点保存）
- 进入观察状态的账号，主界面「名称/备注」列最前面会显示 ⚠ 标记
- 观察账号在主流程和单账号运行中，按下「烽火地带」前会**多执行一步「观察状态入口」**（在模板上传向导中新增的可选模板，蓝色「非必需」，未上传或识别失败则跳过，不影响后续流程）
- 单账号运行识别「烽火地带」入口次数由 5 次降为 **3 次**（所有账号单账号运行时均如此）

----- 冷却执行 -----

- 账号冷却默认开启（无需手动开启）
- 每个账号运行完后自动冷却（默认8小时），冷却时间在账号结束后立即写入本地，任务结束兜底保存（异常重启不丢冷却）
- 冷却到期后自动运行
- 主界面「全体延时+」按钮：一键为所有冷却中的账号延长 30 分钟
- 主界面「冷却缩减-」按钮：一键为所有冷却中的账号缩减 30 分钟，缩减后到期的账号直接变为可运行
- 双击主界面「下次运行时间」列可设置自定义冷却时间（如 8H 30M）；也支持查看冷却状态、重置冷却
- **账号运行分组**：设置 → 自动任务中开启后，账号按「每 N 个一组」运行，每组跑完等待「组间隔」分钟再跑下一组（默认 5 分钟，附建议提示），避免频繁切换账号触发滑块验证；每组账号数和组间隔均可自定义，等待期间主页操作栏显示组间等待倒计时
- **冷却检测等待**：设置 → 自动任务 → 冷却执行中可设主流程后等待 N 分钟内到期的账号（默认10分钟，开启分组运行且设置小于10时自动变为15分钟，避免提前关机漏跑）

----- 一键出售 -----

- 主流程完成后自动打开仓库，逐个出售物品
- 上架后按**固定坐标**点一次「最大数量」把数量挂满（默认 0,0＝不点该步，需要时在模板向导第 30 项「模板设置」→「点击坐标」里填写或屏幕取点）：该点击不叠加随机偏移，也不需要上传对应模板；坐标填 0 表示跳过该步
- 「最大数量」坐标怎么改：设置→全局设置→模板上传向导，找到第 30 项「最大数量按钮」，点它右侧的「模板设置」，在「点击坐标」里填 X/Y 或点「屏幕取点」，然后点「保存坐标」
- 支持降价设置（0-5次）
- 在「设置→售卖物品」中管理要出售的物品图片
- 该页的「出售测试」按钮可单独试跑出售流程：**测试前请先手动进入仓库界面**（测试不会自己打开仓库），并且**不受「售卖时间区间」限制**，什么时候点都能测；测试结束会弹出结果，一件都没卖时会写明具体原因（不在售卖时段／物品列表为空／图片已丢失／找不到仓库入口／收到停止信号），并给出本次日志文件路径

----- 邮箱货币 -----

- 进入游戏后自动打开邮箱
- 进入交易中心领取货币奖励

----- 资产识别与监测 -----

- 进入游戏后自动识别账号资产数值（大厅与操作后各识别一次并对比校验，两次差≤3m且与最近记录≤50m才有效，防误识别）
- 资产记录持久化到 SQLite 数据库
- 可查看指定天数内的资产变化

----- 皮肤抢购 -----

- 在「设置 → 实验功能」中打开「皮肤抢购」窗口
- 设置搜索区域和购买按钮图片
- 程序自动在区域内查找购买按钮，找到后自动点击购买
- 确认购买 3 秒后退出，刷新页面继续监控
- 超时自动停止（默认30分钟）

----- 日志遮罩 -----

- 屏幕左下角透明日志叠加层（默认开启），加粗分级彩色日志，鼠标穿透不影响游戏
- 顶部一行左侧显示运行账号状态，行尾实时显示鼠标坐标
- 遮罩已**排除在屏幕截图之外**（Win10 2004+），所以它盖住哪个按钮都不会干扰找图/OCR；老系统自动降级为「识别失败时让位」
- 遮罩**恒定鼠标穿透、永远不挡点击**；位置在「实验功能 → 更换角落」里切换（左下→右下→右上→左上）
- 关闭方法：托盘菜单「日志遮罩」或「实验功能」窗口取消勾选

----- 自定义操作 -----

- 设置 →「自动任务」页最下方 →「配置自定义操作」打开配置窗口
- 支持九种步骤（顶部「＋ 添加步骤」菜单选择，编辑框内类型下拉为中文）：
  - 找图点击（默认）：框选图标截图或导入图片，匹配后点击
  - 坐标点击：填 X/Y 或「屏幕取点」；鼠标拖拽：起点→终点；鼠标滚轮：上下格数
  - OCR点击：填文字，识别后点击；键盘输入：按键/组合键（esc、Enter、ctrl+a 等）或输入文本（中文等非 ASCII 用剪贴板粘贴；游戏内用 SendInput，Interception 驱动仅用于登录输入账号密码）
  - 多图点击：一个步骤配多张图，按顺序点第一张找到的
  - 条件跳转：找图/OCR 探测，满足则跳转到指定步骤；跳转：无条件跳转（配合实现循环/重试）
- 双击或右键步骤可修改属性，右键可切换步骤类型、上移/下移/删除
- 每个步骤通用属性（编辑框下方）：「重试(次)」失败后自动重试 N 次、「重试间隔(秒)」每次重试等待、「失败处理-可选」勾选后该步找不到图/字不判失败，直接继续下一步（适合可选的界面处理）
- 可勾选「点击受随机偏移影响」让点击带拟人抖动（坐标步骤也会抖动）
- 勾选「主流程完成后自动执行」后，每个账号主流程完成、游戏回到主界面时自动按顺序执行
- 某一步找不到目标（图片/文字）则中止该账号剩余自定义操作，跳到下一个账号
- 窗口左下角「运行测试/停止」可试运行，右下角「保存步骤」保存配置

4. 模板上传
================================================================================

在「设置→全局设置→模板上传向导」中：
1. 所有模板按主流程顺序排列（登录→导航→设施→制造→邮箱→出售）
2. 点击「上传」替换内置模板图片
3. 每次上传一张，上传后自动生效
4. 支持预览当前模板和恢复默认
5. 蓝色「非必需」模板（游戏确认按钮、观察状态入口）可跳过不上传，不影响其余流程；「观察状态入口」仅观察状态账号会用到
6. 「插入步骤」：点某模板「模板设置」→「插入步骤」，可给该模板配置一段自定义步骤，在自动化「识别点击该模板」的**点击前或点击后**执行（顶部下拉选「点击前/点击后」，一段步骤整体一个时机）。适合在某一步前后补充额外动作（如点烽火地带前先做某事）。配置了插入步骤的模板，向导列表最前面的勾会显示为红色 ✔；没配置则照常识别点击下一步

截图规范：
- 建议 PNG 格式
- 保持与游戏内实际显示一致
- 确保图片清晰、无遮挡

5. WeGame 登录说明
================================================================================

本工具在 WeGame 登录界面直接输入账号密码（WeGame 支持多账号单独登录）。
输入由「键盘输入后端」完成，程序会自动挑一个可用的，优先级：
    1. STM32 外部硬件键盘（推荐）—— 插一块专用硬件键盘，不影响你系统里的键盘
    2. Interception 驱动级输入 —— 内核驱动模拟
详见下面 5.1「键盘输入方式」。

自动登录流程：
1. 程序打开 WeGame
2. 自动选择账号输入框，清空旧内容
3. 驱动级输入账号
4. 自动点击密码输入框，输入密码
5. 点击登录确认
6. 找到三角洲游戏图标，启动游戏

如果 Interception 驱动未安装或不可用：
- 安装程序时会提示安装驱动
- 也可以手动运行安装目录下的 install_interception.bat（管理员身份）
- 安装后需重启电脑

驱动验证方法（管理员 CMD）：
    sc query keyboard
    如果显示 RUNNING 则表示驱动正常工作

--------------------------------------------------------------------------------
5.1 键盘输入方式（STM32 硬件键盘 / Interception 驱动）
--------------------------------------------------------------------------------

为什么 STM32 排在最前面：它同样是「真键盘」（游戏认可），但**完全不碰你系统里的键盘**。
而 Interception 是内核键盘筛选器，万一它出问题，会让**整台电脑的键盘都失灵、只能重启**。

STM32 硬件键盘怎么用（不需要任何配置）：
  1. 用 USB 线把板子接到电脑（会自动多出一个 COM 口 + 一个键盘设备，免驱）
  2. 直接运行程序 —— 登录时会自动用它输入账号密码
  3. 日志里会打印「⌨️ 键盘后端: STM32(COMx)」，告诉你当前用的是哪个

「键盘设置」窗口（设置 → 实验功能 → 驱动键盘测试 → 键盘设置）：
  · 选择用哪个后端：自动（推荐）/ 只用 STM32 / 只用 Interception
  · STM32 的串口、打字间隔（越大越像人手动打字）、回执超时
  · 「检测连接」：确认板子连上、能通信（只握手，不按键）
  · 「打字测试」：让硬件键盘往窗口里的输入框打一串测试字符，能一字不差打进去就说明可用
  · 「紧急停止 / 恢复」：对应板上长按 PB1/PB11 触发的那个状态
  · 窗口大小和位置会被记住，下次打开还原
  · 「驱动失败时自动重启电脑」：Interception 驱动不可用时先重启驱动服务，仍失败则 10 秒后重启电脑；
    选「只用 STM32」时这一项会置灰（程序根本不加载那个驱动，勾了也不生效）
  · 选了「只用 STM32 硬件键盘」后，程序**完全不会去加载 Interception 驱动**
    （状态里那一行会显示「– 未检测」）—— 想彻底避开那个内核驱动就选它
  · 即使保留默认的「自动」：只要 STM32 板子可用，程序**也不去碰 Interception**
    （按顺序挑到它就收工）；只有当板子不可用时，才会退回去用 Interception
  · 「实验功能 → 驱动键盘测试 → 测试输入」按这里选的后端测（选「只用 STM32」就测 STM32），
    与登录走同一条路；已不再单独提供「测试 Interception」按钮

⚠️ 运行前请把输入法切到**英文状态**：中文输入法会把硬件键盘打出的字符吃掉或转成全角
   （例如 ! 会变成 ！），账号密码就会输错。

6. 设置说明
================================================================================

常用设置项：

  图像匹配置信度    0.7（建议范围 0.5-0.9，越低越容易匹配到图片）
  WeGame 路径      自动检测，一般无需手动填写
  冷却小时数        默认 8 小时
  额外等待时间      0-120 秒（机器配置较低时可增加游戏启动等待，默认 0）
  一键出售置信度    0.55（独立于图像识别置信度）

所有设置在「设置」窗口中修改，修改后自动保存。

8. 常见问题
================================================================================

Q: 程序无法启动？
A:
  1. 检查是否以管理员身份运行
  2. 检查杀毒软件是否拦截
  3. 查看 %APPDATA%\DeltaAutoTool\error.log

Q: 图像识别失败？
A:
  1. 内置模板基于 2560×1440（2K）屏幕 + 游戏 1440×900 下制作，其他分辨率识别率可能下降
  2. 在设置中降低置信度（如从 0.7 降到 0.6）
  3. 在模板上传向导中查看并重新截图上传

Q: WeGame 登录失败？
A:
  1. 确认已安装 Interception 驱动：sc query keyboard
  2. 确认 WeGame 路径设置正确
  3. 检查账号密码是否正确

Q: 皮肤抢购不工作？
A:
  1. 确认已设置搜索区域
  2. 确认已选择购买按钮图片
  3. 点击「测试搜索」验证图片是否能找到

Q: 滑块验证（YOLO）不工作？
A:
  1. 滑块验证需要模型文件 best.onnx，程序不再内置（减小安装包体积）
  2. 在 设置 → 验证码设置 → 滑块验证 → 「导入模型」选择模型文件，导入立即生效
  3. 导入后可用「仅测试滑块识别」验证；未导入时该功能无法启用

----- 自纠错（可选功能，默认关闭） -----

进特勤处时，有些设施是「已经领取过、但还没开始制造」的空缺状态。开着自纠错的话，
程序会先把这些空缺补上制造，再去跑正常的设施流程（补过的那个设施整段跳过）。

怎么开：
  1. 先在「模板上传向导」里找到第 33 项「制造空缺」，截一张图上传
     （4 个设施的空缺标志长得一样，截一张就够）
  2. 设置 → 自动任务 → 执行操作 下面勾上「自纠错」

不开、或者没截第 33 项模板，都完全不影响原来的流程（程序会自动跳过自纠错）。

它会做的事，一圈一圈来（最多 4 圈）：
  · 先只看一眼有没有空缺（只看不点，确认真有才动手）
  · 有 → 点进去，靠 4 个设施的产出项认出这是哪个设施
  · 补上制造流程 → Esc 回特勤处 → 再看还有没有别的空缺

下面三种情况它会「收手」，而且**不会让这个账号失败**：
  · 没找到空缺 → 正常流程照常跑
  · 认不出是哪个设施 → 收手，不乱点
  · 认出来的设施刚补过 → 收手，避免反复点同一个

----- 出错时的诊断资料 -----

账号最终运行失败时，程序会自动留一份现场资料，方便排查：

  · 整屏截图：保存在「目录及数据/<日期>/错误截图/」里，
    文件名是「备注_时间.png」（该账号没设备注时用账号名）
    —— 想按截图做错误归类，直接看这个文件夹
  · 屏幕文字：同一次失败会把屏幕上的文字识别出来打进日志
    （日志里那行「📋 屏幕文字: ...」）

失败通知邮件里，账号名前面会带上「备注」，多账号时一眼能看出是哪个号出的问题
（没设备注就只显示账号名）。
